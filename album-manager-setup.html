Private Client Album Manager

This is a separate system for client mobile + code login to an existing eAlbum URL. Existing Google Drive Gallery and E-Album Create Admin are not changed.

One-time setup

  1. Open Google Apps Script and create a new standalone project.
  2. Copy album-manager/Code.gs into Code.gs. Add HTML files named Admin and Client and copy the matching files from the repository's album-manager folder.
  3. Run setupAlbumManager() once and authorize it.
  4. In Project Settings → Script properties, add ALBUM_MANAGER_ADMIN_PASSWORD with a unique password (12+ characters).
  5. Deploy → New deployment → Web app; Execute as Me; access Anyone. Copy the URL.
  6. Admin opens the URL. Client login is that URL plus ?page=client.

How to use

Enter client name, 10-digit mobile and ready link like https://view.ealbum.in/?c=73007922M9. Copy the newly generated code and send it privately to the client. Disable access any time from the admin list.

Important: the manager gates access through its login. It cannot make the underlying eAlbum URL private if that URL is shared separately.
